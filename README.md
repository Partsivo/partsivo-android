## العربية

### شنو هو Partsivo؟
Partsivo دليل مغربي لتوافق قطع الغيار: كتقلب على موديل ديال تيليفون (وحتى تابليت، لابتوب ولا كونسول) وكتعرف أشمن قطع كتركب عليه وأشمن موديلات كيتشاركو نفس القطعة: الشاشة، البطارية، الكاميرا، الكونيكتور، الفليكس... المجتمع كيأكد التوافق بالتجربة، واللي كيساهمو كيربحو نقاط (karma) وشارات.

### علاش تصاوب؟
بزاف ديال الناس ف المغرب كيخسرو فلوسهم ف قطع ما كتركبش. ومحلات الإصلاح والبائعين محتاجين جواب سريع: «واش هاد القطعة كتركب على هاد الموديل؟». Partsivo كيجمع هاد المعلومة ف بلاصة وحدة.

### المميزات
- البحث على الموديل والقطعة ومعرفة الموديلات المتوافقة
- تأكيدات المجتمع: التوافق كيتأكد من تجارب ناس حقيقيين
- نقاط karma وشارات للمساهمين
- حساب بـ Google (اختياري للمساهمة)
- الواجهة بالعربية والإنجليزية، مع الوضع الليلي والنهاري
- مجاني

### الإيجابيات والسلبيات (بصراحة)
**الإيجابيات:** مجاني؛ عربي وإنجليزي؛ المعلومات كيأكدها المجتمع؛ نفس الحساب ديال الموقع.

**السلبيات:**
- نسخة Play Store جاية قريب؛ دابا التثبيت من هنا كيتطلب تسمح بـ «مصادر غير معروفة».
- خاص الإنترنت: ما كاينش كتالوج كامل بلا اتصال.
- قاعدة البيانات مازال كتكبر، وشي موديلات ولا قطع ما كايناش.
- معلومات المجتمع يمكن يكون فيها غلط؛ تأكد قبل ما تشري.
- نسخة APK ونسخة Play ما كيتبدلوش ف بعضياتهم: إلا بغيتي تبدل، مسح الأولى عاد ثبت الثانية.

## English

### What is Partsivo?
Partsivo is a Moroccan spare-parts compatibility guide. Search a phone (also tablet, laptop or console) model to see which parts fit it and which models share the same part: screen, battery, camera, connector, flex and more. The community confirms compatibility from real repairs, and contributors earn karma and badges.

### Why it exists
Many people in Morocco waste money on parts that don't fit. Repair shops and sellers need fast answers to "does this part fit this model?". Partsivo puts that knowledge in one place.

### Features
- Search models and parts, see compatible models
- Community confirmations from real-world experience
- Karma and badges for contributors
- Google sign-in (optional, needed only to contribute)
- Arabic and English UI, dark and light themes
- Free

### Honest pros and cons
**Pros:** free; Arabic and English; community-verified data; same account as the website.

**Cons:**
- The Play Store version is coming soon. Installing from here requires allowing "unknown sources".
- Needs an internet connection: there is no full offline catalog.
- The compatibility database is still growing; some models or parts are missing.
- Community data can contain mistakes; double-check before you buy.
- The APK and Play versions can't update each other. To switch, uninstall one and then install the other.

### Which APK?
| File | For |
|---|---|
| `partsivo-universal.apk` | **Not sure? Pick this.** Works on every device (bigger download) |
| `partsivo-arm64-v8a.apk` | Most modern phones (2017+) |
| `partsivo-armeabi-v7a.apk` | Older 32-bit phones |
| `partsivo-x86_64.apk` | Emulators and Chromebooks |

**Important:** keep the same type for future updates (universal → universal, arm64 → arm64).

### Install
1. Download from the [latest release](../../releases/latest).
2. Open it; if prompted, allow your browser to install unknown apps.
3. Tap Install. To update, install the newer APK of the same type over the old one; your data is kept.
